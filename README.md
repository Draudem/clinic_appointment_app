# Голосовой ассистент регистратуры (Команда Иксиканцы)

Бэкенд голосового ассистента для записи на приём. Реализует типовые сценарии телефонного обслуживания по регламенту **РГ-ТЕЛ-01**:
- Запись на приём (С-01)
- Перенос и отмена записи (С-03, С-04)
- Проверка записей (С-05)
- Справка о графике (С-07)
- Перевод на оператора при красных флагах (R-01, R-11) и медицинских вопросах (R-04).

Интеграция с тестовым стендом МИС «Регистратура» (`crm-med-mock.dbi-testing.ru`). Расписание врачей ведётся локально (на основе Excel), контроль свободных слотов реализован на стороне ассистента.

## Быстрый старт
1. Скопируйте `.env.example` в `.env` и укажите `MIS_TOKEN` (токен стенда).
2. Запустите: `docker compose -f deploy/docker-compose.yml up -d --build`
3. Swagger UI: `http://localhost:8090/swagger-ui.html`
